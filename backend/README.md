# FilmLog Backend

This directory contains the Laravel 12 API for FilmLog.

See the repository root [README.md](../README.md) for prerequisites, environment variables, database setup, API reference, security notes, the Gemini grounding strategy, and the Postman collection.

Quick start from this directory: install Composer dependencies, copy `.env.example` to `.env`, configure MySQL and Gemini, then run `php artisan key:generate`, `php artisan jwt:secret`, and `php artisan migrate --seed`.
